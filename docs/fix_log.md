# Журнал правок Verbot

Зачем: ответить цифрой на вопрос «правки бесконечны?».
Одна строка на правку, 30 секунд при коммите.

Колонка **причина** — три значения, других не бывает:
- `код` — детерминированный баг, обучение модели тут ни при чём;
- `промпт` — правило в промпте или материал в data/*.json;
- `веса` — поведение самой модели, кодом не лечится (только режется стражем).

Колонка **живьём** — `да` только после живого урока, не после тестов.

## Счёт за всё время

Смотреть на пропорцию. Если `код` и `промпт` растут, а `веса` стоит на месте —
модель не виновата, идём дальше кодом.
Если `промпт` начинает занимать больше половины — подход промптов исчерпан,
тогда (и только тогда) обсуждаем обучение судьи.
