ruins, volcano, ice (B2) → sky, space (C1).

### Формат файла
`data/words_<уровень>.json`; словарь `themes`: ключ — id блока из
`knowledge_base/curriculum.json` (например `forest/point_1`), значение — список
`{"ru": "...", "en": "...", "example": "..."}`.
**Уровень — в имени файла, тема — в ключе.**

### Правила слов
- `en` — американский вариант; `ru` — одно-два слова;
- `example` — короткое предложение, где форма слова встречается БУКВАЛЬНО
  (иначе окно повторения не построит пропуск);
- дубликатов пар «ru+en» внутри файла нет (проверять скриптом);
- после каждой локации: `tests/test_vocab_theme.py` + коммит + push;
- новые `data/words_*.json` добавлять в git ЯВНО
  (`.gitignore`: `data/*` + `!data/words_*.json`).
