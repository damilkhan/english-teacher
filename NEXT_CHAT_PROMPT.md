## 🎯 ЗАДАЧА ЭТОГО ЧАТА

### Шаг 1. Материал урока — файл `data/lessons_a2.json`

Формат на каждый урок (id как в `curriculum.json`, например `city/4.1`):

```json
"city/4.2": {
  "topic": "Comparing Things",
  "words": ["bigger", "the biggest", "better", "worse", "more expensive"],
  "phrases": [
    {"ru": "Мой город больше, чем этот.", "en": "My city is bigger than this one."},
  ],
  "scene": [
    {"who": "Ann", "en": "Look, two phones! This one is cheaper."},
    {"who": "Jack", "en": "But this one is better. And it is smaller."}
  ],
  "ask": ["Which phone would you take and why?"]
}
```

* **мини-сцена** 4–6 реплик — короткий живой диалог по теме блока и уровню A2;
* **ask** — 2–3 вопроса ТОЛЬКО по сцене (ученик отвечает про то, что услышал);
* **phrases** — 5–8 фраз, которые ученик должен уметь сказать сам;
* тексты пишу я (ассистент), ученик просматривает; модель их НЕ сочиняет.

Задача — чтобы вместо «придумай вопрос про Comparing Things» модель получала
готовую ситуацию: `Jack and Ann are looking at two phones. Say what you think`
и реплику-завязку. Вопросы тогда будут про ЭТИ телефоны, а не про здание на улице.

### Шаг 2. Промпт урока берёт сцену

`prompt_builder._lesson_block` / `_task_cycle_block`: добавить блок «ситуация +
вопросы по ней», если урок есть в `lessons_a2.json`. Нет урока в файле —
прежнее поведение байт-в-байт (иначе поедут `smoke_test` и тесты промпта).

### Шаг 3. Фото по теме урока

`picture_task.describe_task(level, used, topic=...)`: если передана тема урока —
брать картинку с совпадающей темой (`assets/pictures/pictures.json`, у каждой
есть `topic` и `points`). Нет совпадения — как сейчас, случайная по уровню.
В задании мягкая строка: `Try to use: bigger than, the biggest`.
После ответа — строка «использовал / не использовал» БЕЗ оценки и без влияния
на зачёт (зачёт по буквам, как сейчас).

### Шаг 4. Карточки правил для того, что реально ловится

Написать карточки в `data/cards_a2.json`: сравнение (`bigger / the biggest /
more expensive`), `few / a few / little`, `there is / there are`. Формат как у
существующих (`title`, `when`, `examples`, `wrong`, `words`, `hints`, `rule`).
Правило `other` карточкой не закрывать — это свалка.

### Шаг 5. Пилот ОДНОГО урока (как скажет ученик), потом остальные

Проверять живьём: вопросы про сцену, фото по теме, карточка с текстом.
Ничего не «улучшать» попутно. Одна правка — один прогон тестов по теме.
