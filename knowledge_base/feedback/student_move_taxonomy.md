# Таксономия реплик ученика (Student-Move)

## 0. TL;DR для Джейн

Каждая реплика ученика описывается **двумя осями**:

1. **Move type** — что ученик делает (вопрос, ответ, комментарий, подтверждение, off-task).
2. **Move status** — оценивается ли его реплика как правильная/неправильная.

**Ключевое:** только ответы (Answer/Attempt) получают статус «правильно/неправильно». Вопросы, комментарии, подтверждения — **не оцениваются** (Non-evaluable). Это значит: **не исправляй всё подряд**. Исправляй только то, что требует исправления.

---

## 1. Move type — 5 типов

| Тип | Что это | Пример |
|---|---|---|
| **Q — Question / Inquiry** | Ученик спрашивает значение, правильность, объяснение или употребление | «What does *flying colours* mean?» |
| **A — Answer / Attempt** | Ученик пытается выполнить текущее задание, предложение, перевод или задачу на целевом языке | «The result of an exam was a relief for me.» — когда учитель попросил составить предложение со словом *relief* |
| **S — Statement / Explanation / Comment** | Ученик высказывает идею, объяснение, пример или наблюдение, **а не** отвечает напрямую | «I think group 1 is more emotional.» — когда учитель спросил про предлог |
| **F — Feedback / Acknowledgement** | Ученик подтверждает, принимает, отвергает или сигнализирует понимание реплики учителя | «Exactly.» — после вопроса «Is the exam IELTS?» |
| **O — Other / Social / Off-task** | Социальный, эмоциональный, filler или не относящийся к задаче контент | «Oh, it's difficult!» |

---

## 2. Move status — 3 статуса

| Статус | Когда применим | Пример |
|---|---|---|
| **A — Adequate / Accepted** | Только для Answer / Attempt. Ответ удовлетворяет текущему требованию | Правильный ответ, принятый учителем |
| **P — Problematic / Needs Repair** | Только для Answer / Attempt. Ответ неправильный, неполный, неестественный или требует пересмотра | «carears advisor» вместо «careers» |
| **N — Non-evaluable / Open** | Фиксирован для Q, S, F, O. Также используется, когда ответ-подобная реплика не может быть оценена как правильная или неправильная | Открытый вопрос, комментарий, светская беседа |

**Важное ограничение:** только **Answer / Attempt** получает статус A или P. Все остальные типы получают **N**.

---

## 3. Два измерения независимы

**Move type** и **move status** — **разные** вещи. Это критично понимать.

- Move type отвечает на вопрос: *«Что ученик делает?»*
- Move status отвечает на вопрос: *«Нужно ли это оценивать?»*

**Пример:**
- Ученик пишет: «In my last job I worked as a carears advisor...» — это **move type = A** (attempt), **move status = P** (problematic, потому что «carears» — орфографическая ошибка).
- Ученик пишет: «What does *carears* mean?» — это **move type = Q**, **move status = N** (не оценивается).

**Move status описывает task-level evaluability, а не грамматическую правильность всей реплики.** Реплика может содержать языковую проблему, но при этом быть открытым вопросом, а не неправильной попыткой ответа.

---

## 4. Почему это важно для Джейн

Различение move type и move status определяет **три разных решения**:

| Ситуация | Что делать |
|---|---|
| Move type = A, status = P | Оценить ответ: flag / hint / guided revision / correction |
| Move type = Q | Объяснить (Topic Contingent), не исправлять |
| Move type = S / F / O | Продолжить разговор, не оценивать |

**Ошибка, которую допускают плохие тьюторы:** исправляют **всё**, что содержит ошибку. Правильный подход: исправлять **только то, что требует исправления** (status = P).

---

## 5. Что из этого следует для Джейн

1. **Сначала классифицируй реплику ученика.** Что это: вопрос, попытка ответа, комментарий, подтверждение, off-task?
2. **Только Answer / Attempt оценивай.** Всё остальное — Non-evaluable.
3. **Не исправляй ошибки в вопросах и комментариях** — это убивает learner agency.
4. **Различай «правильно/неправильно» (status) и «хорошо/плохо сформулировано» (грамматика).** Ошибка в формулировке не делает реплику проблематичной, если её задача — коммуникация.
5. **Учитывай task-level evaluability.** Если задача — не «ответить правильно», а «поговорить», то status всегда N.
6. **Помни про связку с tutor strategy:** статус реплики определяет, нужно ли вмешиваться и насколько сильно.

## 6. Глоссарий

| Термин | Значение |
|---|---|
| Student move | Реплика ученика в диалоге |
| Move type | Что ученик делает (Q / A / S / F / O) |
| Move status | Нужно ли оценивать (A / P / N) |
| Task-level evaluability | Может ли реплика быть оценена как правильная/неправильная в контексте задачи |
| Learner agency | Самостоятельность ученика |

## 8. Ограничения таксономии (из статьи)

- **Компактная таксономия** полезна для обучения и диагностики, но **реальные учителя смешивают** инструкцию, аффект, темп и раппорт так, что их не всегда можно разделить.
- **Качество следующей реплики ≠ долгосрочное обучение.** Реплика может быть локально хорошей, но её эффект зависит от мотивации ученика, предварительных знаний, повторного взаимодействия и контекста класса.
