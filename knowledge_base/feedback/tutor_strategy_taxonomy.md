# 13 стратегий тьютора (TACT)

## 0. TL;DR для Джейн

Когда ученик что-то сказал — ты выбираешь **одну (или несколько)** из 13 стратегий. Это не то же самое, что «правильно ответить». Это **педагогическое решение**: что именно сейчас нужно ученику.

Стратегии упорядочены **от меньшего вмешательства к большему**. Чем больше вмешательство — тем меньше learner agency (самостоятельности ученика).

**Принцип:** сначала минимальное вмешательство. Усиливай только если ученик не справляется.

---

## 1. Шкала вмешательства (intervention ladder)

← МЕНЬШЕ ВМЕШАТЕЛЬСТВА          БОЛЬШЕ ВМЕШАТЕЛЬСТВА →
Backchannel → Prompt → Social → Verification → Topic Contingent →
Error Flagging → Hint → Clarification Check → Response-Contingent →
Guided Revision → Try Again → Bugs → Correct Response

**Правило для Джейн:**
- Если ученик справился — **Verification** или **Response-Contingent**.
- Если ошибся — начни с **Error Flagging** или **Hint**.
- **Correct Response** (прямой ответ) — только если всё остальное не сработало.

---

## 2. Все 13 стратегий с определениями и примерами

### 2.1 Conversational / tutoring functions (не про исправление)

**Verification** — подтверждает, правильный ответ или нет, без дополнительного объяснения.
> Пример: «That's right!» после правильного ответа.

**Correct Response** — даёт конкретный правильный ответ без объяснения.
> Пример: «It's *careers*!» после того, как ученик написал «carears».

**Topic Contingent** — добавляет релевантный обучающий контент, когда реплика ученика **не является** правильной или неправильной (вопрос, комментарий, наблюдение).
> Пример: «In this context, it means you passed with a high standard; you got a high mark basically.» — после вопроса «what does *flying colours* mean?».

**Response-Contingent** — развивает правильный ответ ученика, предлагая более естественную или полную формулировку.
> Пример: учитель принимает формулировку ученика, затем предлагает более идиоматичный вариант.

**Prompt** — просит следующий ответ, пример, предложение или шаг задания.
> Пример: «Can I ask you to write a sentence using the following information: Pacific / biggest?»

**Backchannel** — кратко подтверждает реплику ученика **без** содержательной коррекции или обучения.
> Пример: «OK, thanks» после попытки ответа.

**Social** — поощрение, похвала, юмор, приветствие, эмоциональная поддержка.
> Пример: «I thought you seemed very fluent...» — перед продолжением разговора.

### 2.2 Corrective feedback (про исправление ошибок)

**Bugs** — диагностирует и объясняет **конкретную** ошибку или заблуждение.
> Пример: «The noun *confusion* is commonly used with verbs like *cause*; for traffic, we would say something like *chaos*.» — после «The accident made a big confusion on the traffic.»

**Error Flagging** — указывает, что конкретная часть **неправильна или подозрительна**, но **не исправляет** её.
> Пример: «Definitely not *the unemployment*.» — после «The unemployment is high in the whole country.»

**Hint** — даёт **направляющую подсказку**, оставляя пересмотр ученику.
> Пример: сигнал обратить внимание на порядок слов, форму глагола, предлог или подразумеваемое значение.

**Guided Revision / Cue** — даёт **рамку, пропуск, набор опций, контраст или суждение**, которые ограничивают пересмотр.
> Пример: «It is very ______ that you will get a double six.»

**Try Again** — прямо просит ученика попробовать снова.
> Пример: «Not quite — try that sentence again.»

**Clarification Check** — проверяет **подразумеваемое значение** неясного или возможно неточного выражения ученика.
> Пример: «Do you mean, 'I was impressed by the film'?» — после «The film gave me impression.»

## 3. Уровни поддержки (assistance level)

| Стратегия | Уровень поддержки | Learner agency |
|---|---|---|
| Error Flagging | Минимальный | Высокая |
| Hint | Низкий | Высокая |
| Guided Revision | Средний | Средняя |
| Try Again | Средний | Средняя |
| Bugs | Высокий | Низкая |
| Correct Response | Максимальный | Минимальная |

**Ключевой принцип:** сигнализировать об ошибке (flagging) сохраняет больше самостоятельности, чем дать исправление (correct response). Точечная подсказка (hint) даёт больше поддержки, чем общее «попробуй ещё раз».

## 4. Маппинг: student move → tutor strategy

Маппинг **условный, а не детерминированный**. Один и тот же student move может требовать разных стратегий в зависимости от:
- уровня ученика (proficiency),
- сложности задачи (task difficulty),
- истории диалога (dialogue history),
- предыдущей поддержки (prior support).

**Примеры:**

| Student move | Возможные стратегии |
|---|---|
| Problematic answer | Error Flagging / Hint / Guided Revision / Correct Response |
| Adequate answer | Verification / Response-Contingent / Prompt (двигаться дальше) |
| Question | Topic Contingent |
| Statement | Backchannel / Topic Contingent / Social |
| Feedback | Backchannel / Social |
| Off-task | Social / Backchannel / Prompt (вернуть к задаче) |

**Для Джейн:** не запоминай маппинг как таблицу. Запомни **принцип**: сначала минимальное вмешательство, усиливай по необходимости.

## 5. Что из этого следует для Джейн

1. **Перед каждым ответом спроси себя:** «Что ученик только что сделал? Какова его цель?» — это определяет стратегию.
2. **Начинай с минимального вмешательства.** Error Flagging, Hint, Backchannel — по умолчанию.
3. **Correct Response — крайняя мера.** Только если hint и guided revision не сработали.
4. **Мульти-стратегия разрешена.** Можно подтвердить (backchannel) и затем дать hint. Но не перегружай — 1–2 стратегии на реплику.
5. **Учитывай уровень ученика.** A1–A2 — больше поддержки, B2–C1 — меньше.
6. **Не путай стратегию с формулировкой.** «Отлично!» может быть Verification или Social — зависит от того, что ты подтверждаешь.
7. **Сохраняй learner agency.** Если ученик может сам исправить — дай ему шанс.

## 6. Глоссарий

| Термин | Значение |
|---|---|
| Tutor strategy | Педагогическая функция реплики тьютора |
| Assistance level | Уровень поддержки (от минимального к максимальному) |
| Learner agency | Самостоятельность ученика в исправлении |
| Corrective feedback | Обратная связь по ошибкам |
| Scaffolding | Поддержка, которая постепенно снимается |
| Student move | Реплика ученика (см. `student_move_taxonomy.md`) |
| Backchannel | Краткое подтверждение без содержания |
