# Интеграция CLT и TBLT

## 0. TL;DR для Джейн

- **CLT** даёт **теоретическую основу**: язык учится через взаимодействие и общение, фокус на смысле.
- **TBLT** даёт **педагогическую структуру**: урок строится вокруг задачи с реальным результатом.
- Вместе они **дополняют друг друга**: CLT — *почему*, TBLT — *как*.
- Итог: одновременное развитие всех 4 навыков + вовлечённость + связь с реальной жизнью.
- Структура урока: **pre-task → task → post-task** (тот же каркас Willis, но с явным CLT-обоснованием).
- Подход **post-method**: не придерживаться одной методики, а комбинировать под нужды ученика.

---

## 1. Почему CLT и TBLT работают вместе

### 1.1 CLT: что даёт

- **Цель** — коммуникативная компетенция (не знание правил, а умение общаться).
- **Средство** — интеракция и общение с фокусом на смысле.
- **Роль учителя** — организатор общения, не лектор.

### 1.2 TBLT: что добавляет

- **Единица планирования** — задача (task), а не языковая форма.
- **Структура** — явная: pre-task, task, post-task.
- **Результат** — конкретный, реальный, измеримый.
- **Баланс** — fluency и accuracy одновременно, а не по очереди.

### 1.3 Синергия

| Аспект | CLT | TBLT | Вместе |
|---|---|---|---|
| Фокус | Смысл | Задача | Осмысленная задача |
| Структура | Свободная | Явная | Явная, но гибкая |
| Результат | Коммуникация | Outcome | Реальный коммуникативный outcome |
| Навыки | Все 4 | Все 4 | Все 4 + интеграция |
| Роль учителя | Фасилитатор | Организатор задач | Фасилитатор + дизайнер |

**Вывод:** CLT без TBLT — «поговорим о чём-нибудь». TBLT без CLT — «сделай задание». Вместе — «сделай осмысленное задание через общение».

## 2. Post-method flexibility (ключевой принцип)

**Суть:** не придерживаться одной методики. Комбинировать:

- коммуникативную интеракцию (CLT),
- task-based активности (TBLT),
- content-focused learning (CLIL / предметный фокус).

**Почему это важно:** в реальном классе (или в приложении с одним учеником) потребности меняются. Жёсткая приверженность одной методике = потеря эффективности.

**Для Джейн:** она должна **адаптироваться**, а не следовать одному сценарию. Один урок — больше CLT. Другой — больше TBLT. Третий — грамматический фокус. Всё зависит от `weak_topics`, уровня и цели сессии.

---

## 3. Что даёт интеграция (outcomes)

- **Все 4 навыка одновременно** — чтение, письмо, аудирование, говорение.
- **Выше вовлечённость** — ученик делает, а не слушает.
- **Peer collaboration** — работа в парах/группах (в приложении — диалог с Джейн).
- **Strategic language use** — ученик выбирает, *как* сказать, а не просто *что*.
- **Мост между классом и реальностью** — задачи имитируют реальные ситуации.

---

## 4. Структура урока: task cycle

Интеграция CLT + TBLT даёт **три фазы**:

### 4.1 Pre-task

- Введение в тему.
- Активация фоновых знаний.
- Полезная лексика **без объяснения грамматики**.
- Цель: снять тревожность, дать опору.

### 4.2 Task

- Ученик выполняет задачу.
- Фокус на **смысле**, не на форме.
- Ошибки допустимы — это часть процесса.
- Цель: **implicit knowledge**, уверенность, fluency.

### 4.3 Post-task

- Разбор: что получилось, что нет.
- **Language focus** — точечная работа над accuracy.
- Обратная связь по **устойчивым** ошибкам (не по случайным).
- Цель: **explicit knowledge**, коррекция, закрепление.

**Важно:** post-task особенно важен на **intermediate и advanced** уровнях. На A1–A2 фокус — на task, language focus минимальный.

---

## 5. Что из этого следует для Джейн

1. **Строй урок как task cycle:** pre-task → task → post-task. Это тот же каркас, что у Willis, но с CLT-обоснованием.
2. **Не выбирай одну методику.** Комбинируй CLT + TBLT под конкретную сессию (post-method).
3. **Развивай все 4 навыка в одном уроке.** Не «сегодня только speaking».
4. **Фокус на смысле в task, на форме — в post-task.** Не смешивай.
5. **Language focus — точечный.** Работай над устойчивыми ошибками, а не над всеми подряд.
6. **Адаптируй сложность language focus под уровень:**
   - A1–A2: минимум, только критичное.
   - B1: умеренно, 1–2 темы.
   - B2–C1: полноценный разбор, включая нюансы.
7. **Связывай задачи с реальной жизнью.** Задача должна иметь outcome, который ученик может представить в реальной ситуации.
8. **Поощряй peer collaboration.** В приложении это значит: Джейн — не экзаменатор, а партнёр по диалогу.

## 6. Глоссарий

| Термин | Значение |
|---|---|
| CLT | Communicative Language Teaching — подход, фокус на коммуникации |
| TBLT | Task-Based Language Teaching — подход, фокус на задачах |
| Task cycle | Pre-task → Task → Post-task |
| Post-method | Отказ от жёсткой приверженности одной методике |
| Communicative competence | Умение общаться, а не знание правил |
| Implicit knowledge | Неосознанное владение языком (через практику) |
| Explicit knowledge | Осознанное знание правил (через объяснение) |
| Fluency | Беглость |
| Accuracy | Точность |
| CLIL | Content and Language Integrated Learning |
