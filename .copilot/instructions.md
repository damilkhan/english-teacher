# EnglishTeacher — решения, запреты, грабли (часть 3 из 4)

## Решения ученика (НЕ переспрашивать)

- Промах в повторении **не понижает уровень** карточки — только переносит на завтра
  (уровень двигает лишь удачный ответ, §49).
- Новые слова каждый день, тематические, **под все уровни A0…C1**; за заход
  5 новых + 5 повторов; тема меняется НЕ по календарю, а по сдаче «Проверки» блока.
- Перед окном слов бот **сначала отвечает по-английски** и договаривает фразу,
  карточки открываются только после речи.
- **Одна главная кнопка**: «Запись» → после верного ответа «Дальше» → на последнем
  слове «Готово». Нижняя «Дальше» в заходе не нужна.
- Похвала каждый раз **разная** (одна фраза ≤ 2 раз за заход), на промахе — редкое
  подбадривание. Всё только по-английски.
- Просьба «давай слова» = **10 НОВЫХ** слов, норма дня не смотрится, лимита в день нет.
  Обязательный автозапуск — по-прежнему 5 новых.
- **Пустой карточки НЕТ**: спрашивать нечего → бот говорит это голосом, окно не открывается.
- Кнопки на старте в чате: «🎓 Провести урок», «📚 Слова», «💬 Свободное общение».
  Кнопки «Мой прогресс» и «Карта» НЕ нужны.

## Самые дорогие грабли

- Эмодзи в облачке — это КАРТИНКА: в тексте 0 символов, в индексах `tk.Text` — 1.
- `tk.Text`: `padx/pady` — одно число; `tkfont.Font.actual("ascent")` — ошибка, нужно `metrics`.
- У CTk-виджетов `bind_all` запрещён → `tk.Misc.bind_all(self, …)`.
- `pack(before=widget)` падает, если виджет ещё не упакован.
- Новые блоки промпта — только флагом и ТОЛЬКО в конец (иначе падает `smoke_test`,
  он сверяет базу байт-в-байт).
- `write_local_file` пишет CRLF и съедает обратный слэш → пути писать через `/`.
- `profile_store.load()` — это ПРОГРЕСС, не профиль.
