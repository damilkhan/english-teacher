## Нельзя нарушать
1. **Числа только замеренные.** Не замерил — сказать «не замерял».
2. **Не объявлять работающим без прогона** — иначе писать «не проверено».
3. **Точечные правки**: якорь встречается РОВНО один раз; не вышло — `git checkout -- <файл>`.
   Сначала читаешь функцию целиком, потом правишь.
4. **Никаких «улучшений заодно»**: одна задача — одна правка.
5. **Перед коммитом `git diff` по своим файлам целиком** — вставка может попасть в докстроку.
6. **Экономия контекста**: код куском ≤ 60–80 строк; большие выводы — в файл.
7. **Сначала план, потом код**; дождаться «приступай».

## Окончания строк (ловушка)
Якорь с переводом строки в CRLF-файле НЕ находится: нормализовать в LF → заменить → вернуть
CRLF → `ast.parse`. Сверять `git ls-files --eol <файл>`.
CRLF: `ui/app.py`, `config.py`, `controllers/*`, `roles/*`, `tts.py`, `glossary.py`,
`profile_store.py`, `lesson.py`, `prompt_builder.py`. LF: `llm_client.py`, `word_bank.py`,
`vocab_lines.py`, `tests/*`, `*.md`.
