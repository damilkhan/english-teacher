## 1. Что это

Локальный ИИ-преподаватель английского «Джейн». GUI на **CustomTkinter**, модель —
локальный **llama.cpp** (Gemma-4-E4B), речь — **faster-whisper** (STT) и **edge-tts** (TTS).
Всё на CPU, VRAM не трогаем.

**Главная цель — прокачка РАЗГОВОРНОГО английского (speaking), а не письма.**
Поэтому: push-to-talk микрофон, голосовые уроки, робот-персонаж с живым лицом,
погружение в английский.

## 6. Как идёт диалог

```
ВВОД
 ├─ текст → InputBar
 └─ голос → push-to-talk → audio_vad → stt_engine → RecordingController
                      ↓
ЕСТЬ ЛИ КИРИЛЛИЦА? (translate.has_cyrillic)
 ├─ ДА и TRANSLATE_ENABLED → hint_bar (перевод), в чат НЕ пишем ← стоп
 └─ НЕТ → в чат «Вы», дальше
                      ↓
ChatController.send() → фоновый поток
 ├─ build_system_prompt(mode, profile, lang, level, student,
 │                      context=RAG, plan=Планировщик, lesson=,
 │                      now=datetime.now(), variety=True, english_only=)
 ├─ LLMClient.complete(messages) → /v1/chat/completions
 ├─ on_message → чат
 ├─ on_response → TTS + лицо
 │    mood.plan_reply делит ответ на куски по настроению → tts.speak(parts=…)
 │    → на начале звука КАЖДОГО куска приходит колбэк → лицо меняет эмоцию
 └─ on_analysis → Аналитик → info_bar + reactions (3 промаха)
                      ↓
TTS: split_by_language → голос по языку (Ava en / Светлана ru)
     → стриминг mp3→PCM→sounddevice → уровень громкости
     → эквалайзер + рот робота
```

**Порядок «Джейн говорит первой»:** `ChatController.begin_lesson()` отправляет
служебную реплику-затравку. Она **не** идёт ни в разбор Аналитика, ни в прогресс,
ни в историю (флаг `_opening`).

## 7. Лицо робота

**Принцип:** тело — кукла (`face_empty.png`), лицо — сменные наклейки
(слои глаз и рта). Все слои выгружены **по общему холсту 661×377** — накладываются
без подгонки.

### Состояния (`character_face.STATES`)
`idle`, `listening`, `thinking`, `speaking`, `happy`, `smile`, `sad`,
`surprised`, `scorn`, `angry` + «говорящие» `speak_happy`, `speak_sad`,
`speak_surprised`, `speak_thinking`, `speak_story` + `story_end`.

### Поведение
| Что | Параметр |
|---|---|
Моргание | `BLINK_DURATION=0.05`, `SHUT=0.08`, `BLINK_FADE=0.02`, `BLINK_MAX_VISIBLE=0.14` |
Взгляд по сторонам | пауза 1.6–3.4 с, удержание `0.75`, жёсткий предел `1.1` |
Смена глаз | `EYES_FADE=0.05` (короткий, иначе кадры с «прищуром») |
Рот в речи | `MOUTH_RATE=6.2` слога/с, три ступени по громкости |
Кивок | `NOD_DEPTH=6` px, после моргания и на паузах речи ученика |
Конец рассказа | `STORY_END`: закрытые глаза **3 с**, потом покой
Смена эмоции | по КОЛБЭКУ из `tts.py` — ровно на начале звука куска (не по часам)

### Жёсткие правила (иначе ученик видит «зажмурилась»)
- **`SQUINT_EYES = (eyes_closed, eyes_closed_shut, eyes_smile, eyes_scorn)`** —
  эти слои ВЫГЛЯДЯТ закрытыми. В «говорящих» состояниях их использовать нельзя.
- `eyes_smile` — линия 19 px, `eyes_scorn` — 24 px: на теле это прищур.
- Смена эмоции **сбрасывает** моргание/взгляд/кивки (иначе «замерзает»).
- Пока идёт `play_sequence`, обычный `set_state` не применяется.

### Сценарий «три промаха → справился» (`reactions.py`)
3 неудачи подряд → верный ответ → **удивление 1.5 с → улыбка 2.4 с** → возврат.
«Непонятный ответ» (`ok=None`) серию не рвёт и не увеличивает.

### Данные

### Занятие
- Типы: `speaking` (только голос), `chat` (только текст), `listening`

- Ранний выход («Выйти») — урок **не засчитывается**, разбор уже записан.

### Вкладки
`CTkTabview` («Чат», «Карта», «Профиль») **внутри левой карточки**;
шапка и эквалайзер — над вкладками. Робот живёт на вкладке «Чат».

## 9. Экспресс-переводчик

Ученик пишет по-русски → над полем ввода появляется английский вариант.
**Это не отправка:** ученик сам решает (вставить, послушать, сказать вслух).

- Одно слово → до **трёх разных значений** с примерами.
- Фраза → одна строка.
- Кнопки: **🔊** послушать, **↺** вставить в поле **в место курсора**, **✕** закрыть.
- Кнопки «Отправить» **нет** — следующий шаг должен быть речью (push-to-talk).
- Скорость: фраза ~0.3 с, слово ~0.7 с (наша же модель). Фразник + кэш на 200.

### Сверка произношения (после подсказки)
Ученик произносит английскую фразу в микрофон → в той же полосе появляется вердикт:
| Вердикт | Что видит ученик | Что дальше |
|---|---|---|
| ✅ `good` (≥`PRON_GOOD`) | «✅ Похоже! «…»» | реплика уходит Джейн, диалог продолжается |
| 🟡 `almost` (≥`PRON_ALMOST`) | «🟡 Почти: «keys» вместо «key»» + 🔊 | в диалог **не** уходит, ученик повторяет |
| 🔁 `off` | «🔁 Попробуй ещё: …» + 🔊 | то же |
| — `unrelated` | ничего | обычный диалог (сказал своё) |

- Эталон — **последняя английская подсказка** (`hint_bar`); для одного слова
  эталоном берётся ПРИМЕР после «—» (`reference_from_hint`).
- Живёт `PRON_MEMORY_SECONDS` = 150 с; кнопка ✕ забывает эталон сразу
  (`HintBar(on_close=…)`). Кнопка ↺ (вставить) эталон НЕ трогает.
- Сравнение — по словам: артикли `a/an/the` и запинки `um/uh` ошибкой не
  считаются (Whisper их теряет); сокращения раскрываются (`I'm` → `i am`),
  числа переводятся словами. Похожесть слова внутри — посимвольно,
  `CLOSE_WORD = 0.60` (`think`/`sink` = 0.67 → «почти», `cat`/`dog` = 0).
- Пороги настраиваются в `config.py`: строже — поднять `PRON_GOOD`/`PRON_ALMOST`,
  мягче — опустить. Код править не нужно.

### Слова копятся сами (этап A — СДЕЛАНО)
Одиночное слово (то, что переводится через `translate_word`, до 3 значений)
**само** попадает в файл прогресса ученика — ключ `vocabulary`, рядом с
`mistakes` и `completed_lessons`. Кнопки «сохранить» нет; фразы и предложения
не сохраняются.

Одно ЗНАЧЕНИЕ = одна карточка: `word` (русское), `en`, `example`, `level`
(0..5), `next_due`, `created`/`last_ok`/`hits`/`misses`.

Лестница (`vocabulary.INTERVALS_DAYS`): 0 новая (спросить можно уже сегодня) →
1 через день → 2 через 3 дня → 3 через 7 дней → 4 через 21 день →
**5 выучено** (больше не спрашиваем).
Удачный ответ = сверка произношения дала `good` («✅ Похоже!») → +1 к уровню
той карточки, чей ПРИМЕР был эталоном. Промах (`almost`/`off`) → −1, не ниже 0,
и спросить завтра.

- Дубликаты не создаются: ключ «слово + значение», регистр не важен.
- Уже выученное слово повторным переводом **не сбрасывается**.
- Пишем через `profile_store.add_vocabulary` / `update_vocabulary_card`
  (мимо `save()`: перевод слова — не занятие, `total_lessons` не растёт).
- Вкладка «Профиль» показывает строку «Слова: всего · к повторению · выучено».
Окно «Повторение» — этап B, см. ниже.

### Окно «Повторение» (этап B — СДЕЛАНО)

Джейн открывает окно САМА при запуске: после приветствия и профиля, когда
готовы модель и распознавание; не чаще раза в день (`vocab_last_session`),
только если есть слова на сегодня и есть микрофон. Перед окном — одна строка
в чат «📚 Давай повторим N слов». Порядок запуска: профиль → модель →
тест уровня → повторение → следующий урок.

В окне ученик видит РУССКОЕ слово и английский пример с пропуском
(«Open the door with this ___.») и произносит английское значение.
Кнопки: **🎤 Запись** (нажать и держать — тот же `RecordingController`,
второй путь к микрофону не плодим), **🔊 Послушать**, **💡 Подсказка**,
**Позже**, **Дальше** и итог захода («Верно · промахи · отложено»).
Окно модальное, стиль `BlockPanel`; `grab_set` не мешает ни микрофону,
ни озвучке. Распознанный текст уходит В ОКНО (`accept_text`), а не в чат.

Правила захода (договорены, не переспрашивать):
- удачный ответ = вердикт GOOD («✅ Похоже!») → уровень +1;
- промах («🟡 Почти» / «🔁 Попробуй») → −1, не ниже 0, спросить завтра;
- **подсказка = промах** (слово не вспомнилось само); берётся ИЗ КАРТОЧКИ,
  без модели и сети — повторение идёт, пока модель ещё грузится;
- ОДИН итог на карточку за заход: первый результативный ответ двигает
  уровень, дальше можно повторять для тренировки — уровень не шевелится;
- «Позже» → без изменений, слово вернётся в следующий раз;
- сказал по-русски → это НЕ ответ: «По-английски: key» + 🔊, ждём;
- нет микрофона → окно не открывается;
- за заход — 5 слов (`VOCAB_SESSION_SIZE`).

Выключатель автоповторения — `VOCAB_REVIEW_ON_START` в `config.py`.
Остался этап C: вплетать слова в разговор необязательным блоком промпта
(`prompt_builder.py` — НЕ трогать до этапа C, правило §10).

## 12. ГРАБЛИ (собраны по факту, не повторять!)

### Tk / CustomTkinter
1. **`tk.Text` `padx`/`pady` принимают ТОЛЬКО одно число** — отступы делать внешним `pack`.
2. **`window.after(0, fn)` из чужого потока** работает только при запущенном
   `mainloop` → использовать `controllers/dispatcher.py`.
3. **`pack` отдаёт место ПЕРВЫМ упакованным** — виджет, упакованный последним,
   на низком окне сжимается до нуля. Для полос над вводом — `pack(before=chat_view)`.
4. **`CTkTabview` вызывает `command` ТОЛЬКО по клику мыши** — программный `set()`
   вкладку не будит. Решение: подкласс `_Tabview` в `ui/app.py`.
5. **Свой метод `_draw` в наследнике `CTkFrame` конфликтует** с внутренним `_draw`
   customtkinter (падает при создании) → называть иначе (`_redraw_map`).
6. **У `CTkTextbox` НЕТ метода `count()`** — считать позицию каретки по внутреннему
   `tk.Text` (`self._field`), иначе вставка уходит «в конец».
7. **У текстового поля со `state="disabled"` команды `delete`/`insert` молча
   НИЧЕГО не делают** (без исключения) → писать через временное включение
   (`_replace_field_text`).
8. **Тултип поверх кнопки = мерцание**: курсор уходит на тултип → `<Leave>` →
   тултип скрывается → `<Enter>`… Ставить **под** виджетом.
9. **Tk рисует эмодзи одним тоном** → значки делать Pillow (`ui/emoji_render.py`).
10. **`ImageTk.PhotoImage` без сохранённой ссылки** — картинка исчезает.

### Анимация и производительность
11. **Шаг времени анимации считать по РЕАЛЬНЫМ часам**, а не «по кадру» —
    иначе при редких кадрах всё идёт вдвое медленнее.
12. **Не перерисовывать кадр, если он не изменился** (кэш по ключу: глаза+рот+сдвиг).
13. **`PhotoImage` создавать только при смене кадра** и кэшировать — иначе окно виснет.
14. **Эквалайзер: трогать только изменившиеся квадратики.** Перекраска всех 150
    за кадр ≈ 5.5 мс → лаги. Стало 2 вызова, 0.016 мс.
15. **Смена эмоции должна сбрасывать** моргание/взгляд/кивки, иначе состояние «замерзает».
16. **Пиксельные шрифты чёткие только на «родных» размерах** (проверять пиксельно).

### Python / Windows
17. **Tk не грузит шрифт по пути** — только установленные. Решение:

20. **Переводы строк:** большинство файлов CRLF. `write_local_file` пишет LF →
